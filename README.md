# SafeMed Agenda

Sistema acadêmico de agendamento para clínicas de pequeno porte, desenvolvido para a disciplina Prática Profissional em Análise e Desenvolvimento de Sistemas.

## Funcionalidades implementadas

- Cadastro de pacientes
- Cadastro de profissionais
- Consulta da agenda por profissional e data
- Agendamento de consultas
- Validação de conflito de horário
- Remarcação de consultas
- Cancelamento de consultas
- Armazenamento local com localStorage

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- localStorage
